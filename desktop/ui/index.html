模型服务

本地规则优先；启用模型后，未知字段可请求匹配建议。

模板使用正式 API 密钥；模型 ID 可修改。切换服务商不会复用其他服务商的密钥。

测试会经过本地网关向模型发送虚构邮箱字段，检查鉴权、响应 JSON 和字段匹配协议，可能消耗额度。修改配置会停止当前 Agent 会话，请先完成或停止任务。

连接 Chrome / Edge

  1. 打开插件目录，复制目录路径。
  2. 打开浏览器扩展管理页，启用“开发者模式”，选择“加载解压缩的扩展”，载入该目录。
  3. 导出配对文件，在扩展设置中导入完成一次性配对；令牌只保存在浏览器会话内。
  4. 在扩展设置中读取桌面资料；进入招聘页面，扫描并核对字段后启动 Agent。

配对码 / 配对文件包含一次性配对码，10 分钟内有效，配对成功或重新获取后即失效，不含长期令牌。在扩展设置的「连接桌面端」中粘贴配对码即可一步完成连接。当前使用解压缩扩展，安装包更新后需在浏览器中重新加载扩展。
