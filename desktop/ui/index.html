连接 Chrome / Edge

完成一次配对，之后自动重连。

  1. 打开插件目录，复制目录路径。
  2. 打开浏览器扩展管理页，启用“开发者模式”，选择“加载解压缩的扩展”，载入该目录。
  3. 在插件中点击“自动发现并连接桌面端”，首次在本窗口允许一次即可。
  4. 进入招聘页面扫描并核对后填写；已有插件资料不会被首次连接覆盖。

配对码 10 分钟内有效，配对成功或重新获取后即失效，不含长期令牌。安装包更新后需在浏览器中重新加载扩展。
