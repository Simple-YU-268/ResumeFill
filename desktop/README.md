# ResumeFill Agent Windows 桌面端 0.12.0

桌面程序内置 Electron 的 Node 运行时、本地 Agent 服务和 Chrome / Edge 扩展，无需另外安装 Node。关闭桌面端会停止其管理的服务；任务不会自动重放。默认端口 17322，与旧版手动启动的 17321 服务区分。

## 可视化资料编辑

个人资料按基本信息、教育经历、工作 / 实习、项目经历、技能与简介、补充信息、网站补充答案和其他资料分类展示。填写中文表单即可修改信息，不需要编辑 JSON。

- 教育、工作和项目支持多条经历的添加、删除，支持撤销上次删除。
- 补充信息可添加文字、数字或是 / 否字段。已有地区层级、嵌套对象和列表自动展开编辑。
- 网站补充答案显示问题和来源，可修改答案；原有匹配上下文继续保留。
- 修改后点击“保存资料”。邮箱或数字输入错误时会提示，切换分类不会跳过校验。
- 导入文件中的额外字段、隐藏的匹配与归一化信息会保留，不会因表单未展示而丢失。
- “导出已保存资料”导出的是已保存版本，编辑后请先保存。JSON 仍作为内部存储和交换格式。

## 固定选项与同义词

性别、政治面貌、民族、学历 / 学位、婚姻状况等改为下拉选择。原资料中不在选项内的值会保留为原有资料，不会自动改写。填表和回读验证共享同义词词典；例如“中共党员 / 党员”“共青团员 / 团员”“本科 / 大学本科”。预备党员与正式党员、群众与无党派人士严格区分；多个候选含义相同时停止自动选择。

## PDF 简历 AI 解析

1. 先在模型服务中启用并保存兼容 Chat Completions 的模型。
2. 在个人资料中点击“导入 PDF 简历”。读取在独立子进程完成，不会自动发送给外部服务。
3. 展开原文预览，检查多栏排版和文字提取顺序。勾选允许发送简历文本后，点击“调用 AI 解析简历”。
4. 模型将简历语义整理为基本信息、教育、工作、项目、技能和补充信息。系统校验返回字段结构，提示模型不确定之处。模型建议仍需人工核对，可能出错。
5. 新字段默认勾选，已有内容默认不勾选。勾选已有字段代表替换该值，经历按新记录追加。
6. 点击“将勾选项写入编辑表单”，核对后点击“保存资料”。未勾选的原有资料和匹配信息继续保留。

支持文字版和扫描图片 PDF，最大 15 MB / 15 页 / 60000 字符。内置离线 OCR，识别简体中文、繁体中文和英文；加密或损坏文件会提示读取失败。AI 请求最长 60 秒，仅发送提取的 PDF 文本，不附带本地现有简历。语义解析使用桌面端保存的模型接口和密钥，可能消耗模型额度；没有配置模型时不会伪装成 AI 解析。

开发测试通过真实 PDF 文件提取、模拟模型的完整调用和实际打包程序的预览合并；未配置真实外部模型。

## 本地 OCR

PDF 识别默认采用自动模式，按页检查文字层。文字过少或存在明显乱码时，将页面渲染为图片，使用内置 Tesseract.js 引擎识别。文字页和扫描页可以混合；原有文字页不会重复 OCR。检测是启发式的，多栏排版、较长页眉或错误文字层可能导致漏识别，此时可切换“全部页面使用 OCR”。

OCR 引擎、WASM 与三个语言包均随 Windows 安装程序内置，识别无需网络，也不会自动上传 PDF。识别在独立子进程内完成，不写入原文日志或永久图片缓存。界面显示当前页和进度，可点击“取消读取 / OCR”结束并重试。

低置信度会显示待核对提示；识别后仍需确认文本，再授权交由配置的模型进行语义解析。OCR 不推断原图里没有的事实，不保证号码、姓名和日期百分之百准确。单次 OCR 最长 5 分钟；横向、倒置、手写或模糊扫描件建议先旋转或提高清晰度。

合成中英扫描页在本机实测约 2.5 秒，速度因硬件、页数和版式而变化。完整流程已测试：扫描 PDF → 离线 OCR → 模拟模型语义解析 → 逐项核对 → 保存 JSON。

## 网页 OCR 标签识别

需要桌面端运行并已导入本地连接。打开招聘页面并刷新，在扩展中点击“本地 OCR 识别图片标签”。扩展仅在主动点击时获取当前可见页截图，传至本机服务，不上传模型、不保存截图。识别前在内存图像中遮住已扫描的输入框和下拉控件区域，减少已填值对识别的干扰。

识别结果按文字位置与真实可见控件关联。现有 DOM / ARIA / 站点规则标签优先，不被 OCR 覆盖；只为缺少明确标签的控件提供建议。核对标签并勾选，再点击“确认勾选的 OCR 标签并更新匹配”，此时尚未填写。继续核对字段路径和填充值后，可手动填写或启动 Agent。

OCR 期间及确认前请勿滚动、切换页面或修改页面结构。页面、位置或结构变化会使建议失效，需重新识别；触屏捏合缩放暂不支持，普通浏览器缩放和设备像素比通过截图尺寸换算。可点击“取消网页 OCR”。

当前仅支持可见视口中的图片 / Canvas 标签旁存在真实 DOM 输入控件的场景。无真实控件的全 Canvas 表单、图片下拉选项、跨域 iframe、离屏字段、模糊或多义标签仍需人工处理。不会依据 OCR 坐标直接点击，也不会自动提交申请。截图可能包含其他页面内容，因此仅应在自己的招聘表单主动使用。

## 开始使用

1. 安装 `ResumeFill-Agent-0.12.0-Setup.exe`，打开 ResumeFill Agent。
2. 在个人资料中点击“导入资料”，导入已有文件；也可以直接在中文表单中填写并保存。桌面数据默认保存在 `%APPDATA%/resumefill-desktop/`，可通过“打开数据目录”查看。
3. 按浏览器扩展区域中的步骤，开启 Chrome / Edge 开发者模式，加载插件目录。该版本未上架商店，不能静默安装浏览器扩展。
4. 导出连接文件，在扩展设置页导入并保存，授权本机服务。浏览器重启后需重新导入连接令牌。
5. 在扩展设置中点击“从桌面端读取资料”，核对并保存。扩展产生的新答案可通过“将扩展已保存资料同步到桌面”写回。同步为明确的整份覆盖，读取时先载入编辑器，未自动合并。
6. 进入招聘页面，扫描、核对后启动 Agent。桌面显示扩展连接和任务概况；任务控制、字段建议确认仍在扩展弹窗完成。

扩展设置页打开时每 30 秒更新连接，Agent 状态变化时也更新。90 秒内没有心跳的扩展不会显示为在线。连接文件包含本地令牌，模型密钥仅保存在桌面本地配置，不导入扩展。模型配置会重启服务并清空内存任务，请先停止任务。没有配置外部模型时使用本地规则。

升级桌面程序后，浏览器扩展管理页需要重新加载扩展。卸载程序保留个人资料；如需清除，可手动处理自己的数据目录。当前安装包未代码签名，尚未加入自动更新或商店发布。

## 开发与构建

```powershell
cd resume-fill/desktop
npm ci
npm run prepare:resources
npm test
npm start
npm run dist
```

构建使用运行文件白名单，不包含 `resume.json`、个人工作区、令牌、测试资料。安装包输出至 `resume-fill/dist/desktop/`。依赖版本由 package-lock.json 锁定。

桌面页面使用 sandbox、contextIsolation，关闭 nodeIntegration，预加载层只暴露固定 IPC 操作；本地服务仅监听回环地址，对扩展请求检查 Host、Origin 和访问令牌。

CI 使用 `node desktop/ocr-test.cjs --engine-only` 验证真实离线识别、混合页、强制模式与取消，不依赖无人值守环境的桌面图形会话。完整桌面交互和扫描件到 JSON 的流程使用 `node desktop/ocr-test.cjs`，并在实际打包程序上另行验证。
