# 0.27.1 · Element 下拉与级联修复（开发测试版）

日期：2026-10-28。本轮交付扩展测试包，未发布正式 Release。

- 修复普通 Element 下拉对外层容器点击无效，改为点击内部输入触发区及真实选项标签。
- 支持 Element 单层、异步多级级联，不再把 `.el-cascader` 内的输入框当作普通文本框或重复扫描。
- 支持触发区动态 `aria-describedby` 与当前菜单的关联；仅接受同文档、同根内的已知菜单，不把普通说明文字当成选项列表。已有明确关联时不跨控件寻找其他浮层。
- 完整路径逐级选择并检查叶节点，支持 `>` 和 `/` 路径显示；没有完整上级路径时不猜测。选择后独立回读并等待稳定，回空不能计为成功。
- 拒绝禁用控件、禁用选项和层级不符；保持已有内容、取消、文档及区块隔离机制。

真实页面：南京交通集团智联报名表，仅检查 DOM 结构、打开及关闭列表，没有修改申请人答案或保存、提交报名。新代码的填写验收使用实际安装 Edge 扩展与合成 Element 控件，不能视为当前真实页面已完成插件复测。

工作区存在其他未提交的模型与连接修改，本版不提交这些修改；扩展包从本版 Git 提交导出，避免夹带并行工作。

加载新版扩展不会替换已经打开页面的旧脚本。请先保存网页已填内容，再重新加载扩展、刷新表单并扫描。现有桌面端协议 2 可继续连接本扩展，无需重建配对凭据。
