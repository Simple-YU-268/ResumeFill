# ResumeFill Agent 0.24.0

家庭成员资料按人物归属：在“新增家庭成员”中先选择与本人关系，再扫描，父亲姓名和身份证对应 `family.father.name`、`family.father.idNumber`，不会复用本人资料。桌面资料新增家庭成员分类。

插件可开启“自动记住手动填写的家庭成员（仅本机）”，默认关闭。只保存明确成员的手动新增内容；已有不同值需通过学习预览核对。关系变化、未指定成员和可能有多人的关系停止自动匹配。自动记忆不提交网页，不自动将插件资料覆盖回桌面。

规范证件字段是 `idNumber`，兼容读取旧 `IDnmber` 等拼写。请更新后重新加载扩展，保存网页内容后刷新页面再扫描，替换旧脚本。

验证使用合成资料，覆盖成员路径、跨成员隔离、旧扫描保护、学习与 AI 校验、本地手动记忆和桌面编辑。未在用户实际申请页面保存或提交数据。
