# 0.25.0 · 评审修复版

此版本为开发测试版，尚未正式发行，也不代表当前真实招聘页已经通过上游模型完整验证。

- 修复隐私扫描漏检两字中文姓名、家庭身份和错误路径脱敏；归档读取失败阻断发布。
- 打包资源重新生成，检查扩展入口的脚本、样式和图片依赖，独立网关版本跟随包版本。
- 修复损坏配置导致启动崩溃、多字节配对码异常、超限请求持续累加及单字段回读异常影响整批的问题。
- AI 选项使用本地优先、拒绝敏感身份值外发；Agent 按字段约束候选；模型混合响应逐条校验，重复冲突不采纳。
- OCR 复用本地进程和语言模型，空闲五分钟回收，取消、故障和停服时销毁。
- 扩展与桌面共用可视化资料编辑器；高级 JSON 编辑可折叠。新增本机累计统计、可见取消与逐项进度。
- 静态主题与首屏插画、统一 token、窄窗口布局、分步更新说明和可诊断错误；支持可选的模型思考模式。
- 逐项处理表见 `docs/reviews/2026-10-22-resolution.md`。商店上架、代码签名与真实用户走查仍有外部依赖。
