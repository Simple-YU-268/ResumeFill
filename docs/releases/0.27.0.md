# 0.27.0 · 有限自动恢复（开发测试版）

日期：2026-10-26。未正式发行，不自动提交申请。

## 本版功能

- 受控 Agent 对延迟选项、控件重绘及选择回空分类处理，按需等待、重扫、重新绑定并独立回读。
- 每字段最多恢复 2 次、全程最多 3 轮、24 个工具步骤；单次等待不超过 1500ms。可取消，也可关闭自动恢复。
- 只对已核对的字段调整省市区、年月日依赖顺序，不增加批准范围。
- 重绑要求文档、根、容器、模块与唯一语义身份一致。页面刷新、资料变化、容器替换或归属不明即停止；已有不同内容不覆盖。
- AI 只能从限定策略中返回策略与字段 ID。恢复请求仅含控件类型、错误分类、次数和预算，不含网页标签、网址、选择器或简历值。合法的人工处理建议会停止自动恢复；模型失败或无效响应使用有限本地策略。
- 新桌面端声明 Agent 协议 2；旧客户端保留基本执行，不启用新恢复工具。更新不重建个人资料或配对凭据。

## 验证与限制

用户本轮明确允许手工构造页面测试。实际安装 Edge 扩展覆盖异步选项、重绘、级联、回空、歧义、保留已有值、取消、页面和资料变化，以及错误模型响应与 401 降级。构造页面不代表真实招聘站实测。

同版本模拟模型链路已验证字段建议、人工核对、填写回读，以及策略规划→重扫→重绑→核对。2026-10-26 使用桌面端已保存配置进行 Live AI 验证，OpenRouter 返回 HTTP 401，未进入推理。不得将模拟服务结果表述为真实模型可达。

跨域 iframe、封闭 Shadow DOM、未适配的只读自定义控件仍不自动处理。回读一致不代表网站服务端保存。缺少真实站点及成功 Live AI 证据，仅提供开发测试包，不发布正式 Release。

兼容修复：Agent 保留明确核对的自定义资料及经过当前页面/分组重新验证的已学习答案；不将这些授权路径扩展为 AI 候选。已有综合扩展测试已覆盖 20 项授权与独立回读。
