# 0.28.0 · 内嵌网站工作区（开发测试版）

日期：2026-11-12。保留 Electron 与扩展链路，本轮加入独立的网站工作区；尚未发布正式 Release。

桌面概览点击「打开网站工作区」，输入网站地址后可自行登录。网站使用独立持久会话，支持登录弹窗、前进、后退、刷新及外部浏览器入口。扫描后核对右侧资料候选，再填写选中字段。多表单文档和工作记录需明确选择。提交前检查只给出待核对项，最终保存或投递始终由用户在网页完成。

资料管理中导入的 PDF 作为原始附件保存；工作区先选择目标，再确认上传，不生成或改写 PDF。页面、资料或附件变化后需要重新扫描或确认。文件已选中不能证明服务器已接收，须核对网页上传结果。

网站视图没有 Node 或管理界面桥接，所有业务命令来自本地核对面板，填写值由宿主按允许的候选路径重建。引擎在隔离世界运行；跨域和不透明来源在脚本执行前被排除，可见同源 iframe、经验证 srcdoc 和开放 Shadow DOM 沿用共享引擎边界。

测试使用合成资料和本地网站。实际招聘站的登录供应商、风控、组件兼容性仍需逐站验收；外部浏览器扩展继续可用。内嵌工作区暂未接入任务队列、站点规则编辑和 AI 恢复入口。完整模块剩余工作见 `docs/ENGINE-IMPLEMENTATION.md`。

验收：标准 16 组、浏览器 27 组、桌面集成及原生 Electron 五项通过。安装包构建成功，打包程序通过登录弹窗、会话重启、候选防篡改、原始 PDF、变化失效、同源/srcdoc/跨域和 900px 布局测试；打包宿主与 UI 对照源码一致。源码及产物隐私检查通过（产物扫描 1129 项）。本轮未安装覆盖用户现有版本，也未发布或推送。
