# ResumeFill Agent 0.23.0

修复“桌面已有民族、插件却提示资料为空”的同步断层。字段路径原本已识别，问题在于自动重连保留插件旧资料，却没有提示桌面内容发生变化。

## 现在如何使用

桌面端保存资料后，重新打开插件，或点击“检查桌面资料更新”。核对两端差异，点击“同步所选到插件”，再重新扫描网页即可。

- 空缺普通字段默认勾选；已有值、敏感资料和整组经历需要选择。
- 敏感资料和整组经历另需确认。经历数组不会按下标自动认定是同一条记录；选择整组意味着替换该组，请核对。
- 桌面空值不清空插件内容，插件独有字段和网站学习答案保留。
- 同步前重新核对两端资料；资料改变、未保存编辑或 Agent 尚未结束时阻止保存。
- 同步后使旧扫描失效，提示重新扫描；跨窗口保留未保存草稿。
- 同步前保留一份 `resumeSyncBackup`。当前无独立可视化恢复入口，重要资料仍建议导出 JSON。

## 安装与更新

下载 EXE，或在桌面运行总览点击“一键更新并重启”。更新前保存资料和网页内容，完成或停止当前任务。安装后在 Chrome / Edge 扩展管理页**重新加载 ResumeFill**；保存网页内容后刷新旧表单并重扫，避免继续运行旧脚本。

附件包含 Windows x64 安装包、独立插件 ZIP、SHA256SUMS、更新元数据和块映射。安装包未代码签名，扩展尚未上架商店；请从本仓库下载。

## 验证

9 组基础测试及真实安装扩展中的差异同步、自动配对、资料学习、插件 AI / 回读回归通过。同步用例验证了民族空缺、已有资料与学习答案保留、敏感确认、两端过期预览、未保存编辑、Agent 保护与同步后扫描失效。本机动态端口异常的网关用例使用独立测试端口验证，未改变生产监听配置。

公开源码与最终打包运行时完成隐私扫描。申请仍由用户提交；两端资料不是实时双向合并。该版本不会自动把插件资料整份覆盖回桌面。
