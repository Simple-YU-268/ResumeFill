# 0.25.3 版本说明（开发测试版）

发布日期：2026-10-23

## 本次变更

### AI 校准记录（仅本地）

- 扩展现在会记录 AI 建议的匿名质量事件：提出建议（proposed）、被校验拒绝（filtered，含原因类别）、被应用（applied）与填写回读结果（readback）。
- 每条事件只包含：时间戳、事件类型、模型名、网关主机名、资料路径（如 `basics.email`）与置信度。**不包含**简历值、选项文字、页面标签、网址或提示词。
- 数据保存在浏览器本地（`aiCalibration`），环形保留最近 500 条，不发送给任何服务器；记录失败不影响填表流程。
- 用途：后续评估本地规则与模型的建议质量（采纳率、回读通过率），为 0.26 的匹配优化提供依据。

### 图标

- 新增扩展图标（16/32/48/128）与桌面端图标（256）：同一「buddy 简历小人」剪影——品牌绿底、奶油色简历纸、蓝色对勾徽章。
- `manifest.json` 补齐 `icons` 与 `action.default_icon`（商店上架的硬性要求）。
- 桌面端侧边栏品牌位由字母「R」方块改为新图标；桌面安装包使用 256 像素图标。
- 图标由 `scripts/build-icons.cjs` 从矢量剪影生成，可重复构建。

### 打包与检查

- `scripts/check-runtime.cjs` 现在同时校验 `action.default_icon` 引用的资源存在。
- `desktop/prepare.cjs` 支持复制子目录资源（如 `icons/`），并在打包前创建目标目录。
- `scripts/check-release.cjs` 要求 CHANGELOG 包含当前版本条目（0.25.2 起生效的发行判定线，见 [RELEASE-GATE](RELEASE-GATE.md)）。
