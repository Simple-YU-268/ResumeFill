# ResumeFill Agent 0.24.1 — 开发测试版

本版继续排查“插件下拉选中后回空”，包含 0.24.0 的家庭成员独立资料与下拉稳定性修复。

- 新增页面脚本版本检查：先检查旧脚本，再注入模块；避免新旧控件代码混用。检测到旧页面时停止填写，提示保存内容并手动刷新。
- 扫描后的旧路由和填写预览同步失效，Agent 也不能继续执行过期扫描；不自动刷新或清空网页。
- 过滤实际已禁用的 Layui 下拉；失败检查点区分真实选择被清空和只有显示文字被清空，只增加布尔状态及版本号，不增加填写值日志。

更新后重载浏览器扩展，保存已填网页内容，再手动刷新表单并重新扫描。单独重载扩展不能保证已有网页更新了脚本。

隔离验证包括批量重绘、后续字段清空前项、过期脚本拒绝执行、iframe 归属、刷新恢复，以及固定摘要的原版 Layui 普通/搜索 × 静态/重绘四种组件场景。目前用户没有可供复测的实际表单，因此保留为本地测试版，尚未正式发行，也不宣称真实页面问题已完全解决。
