# ResumeFill Agent 1.0.0

发布日期：2026-11-12。辅助简历填写正式发行版。

## 本版交付

- 本地个人资料编辑、JSON 导入导出、PDF 文字提取与离线 OCR、可选 AI 建议，以及确认后学习网页已填内容。
- 扫描可见表单，核对字段和教育、工作、实习等记录归属，填写受支持控件并独立回读。匹配歧义、敏感信息与未适配控件交由用户核对。
- Electron 内嵌网站工作区：独立持久登录会话、前进后退、登录弹窗与外部浏览器入口。网站与应用管理界面隔离。
- Chrome / Edge 扩展与内嵌浏览器复用填写引擎；桌面与扩展提供授权配对、资料差异同步和授权撤销。
- 应用内导入的原始 PDF 经文件与目标确认附到当前表单。Moka、北森上传后使旧计划失效，待网站解析完成后重新扫描、核对再填。
- Moka、北森、智联校招的可见页面工作流识别；登录、验证码、职位限制与志愿确认由用户处理。北森增加独立卡片、字段标签和 Phoenix 单选适配。

最终申请由用户在网页提交。本版不自动提交，不生成 PDF，不代填密码、安全答案或验证码。

## 安装与更新

Windows x64 用户下载 `ResumeFill-Agent-1.0.0-Setup.exe`，也可在桌面端手动启动更新。安装版包含运行环境、扩展和离线 OCR，无需安装 Node.js。

独立扩展下载 `ResumeFill-Extension-1.0.0.zip`，解压后在 Chrome / Edge 的扩展管理页启用开发者模式并加载目录。已有扩展升级后应重新加载；保存网页内容后刷新旧表单，再扫描填写。扩展尚未上架商店，Windows 安装包尚未代码签名。

更新前保存资料与网页草稿，完成或停止当前任务。内嵌浏览器需要自行登录网站；外部浏览器登录不会自动迁入。备份重要资料的 JSON 导出。

发行附件包含安装包、独立扩展 ZIP、`SHA256SUMS.txt`、`latest.yml` 与安装包块映射。校验和用于核对下载完整性。

## 兼容范围与已知限制

平台适配已使用合成页面、实际安装的扩展及原生 Electron 测试；本版尚未完成真实招聘站逐站、逐租户验收。智联研究对象为校招流程，不代表覆盖智联全部产品。Phoenix 多选、复杂地区联动、部分只读日期及未适配控件仍需手动处理。文件被选中或回读一致，不代表服务器已接收、解析或保存。

仅处理当前可见表单、可见同源 iframe、经验证的同源 srcdoc 与开放 Shadow DOM；跨域及不透明文档不填写。资料与页面变化会使旧授权或计划失效，需要重新核对。

AI 为可选功能；默认字段建议仅发送标签与候选路径，PDF AI 解析另需授权发送提取原文。自动恢复的 Live AI 曾遇到认证失败，本版不承诺真实模型或全部供应商已验证可用。

1.0 的发行范围是已实现的辅助填写流程。完整 M1–M9 架构的剩余功能、真实网站验收与后续完善继续记录在 [实施状态](../ENGINE-IMPLEMENTATION.md)，本次发行不表示这些工作全部完成。平台研究范围见 [工作流研究](../PLATFORM-WORKFLOW-RESEARCH.md)。

## 发布验证

`npm run test:all` 退出 0：基础 16 组、浏览器 29 组、桌面集成与六项原生 Electron 测试通过。最终打包程序额外通过完整网站工作区与平台适配原生测试，包括登录会话、原始 PDF、900px 布局及跨域脚本拒绝。模拟 AI、离线 OCR 与网页 OCR 回归通过；模拟模型结果不作为真实模型可用性的证据。

`npm --prefix desktop run dist -- --publish never` 构建成功。`release:check`、`format:check` 与 `git diff --check` 通过；源码隐私检查 226 项、源码与产物合计检查 1137 项均无发现。包内宿主、preload、工作区 UI 和允许清单中的扩展文件与源码一致，独立扩展 ZIP 的 49 个文件与准备好的运行时逐字节对应。更新元数据的版本、文件大小与 SHA-512 已核对。本次没有覆盖安装本机现有应用。
