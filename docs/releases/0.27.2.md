# 0.27.2 · Impeccable UX/UI 重构（开发测试版，暂停发布）

日期：2026-10-30。用户选择暂停创建 GitHub Release，先补齐正式版门禁。

## 变更

- 按 Impeccable Operate、layout、adapt 与 polish 指引重构桌面端、扩展弹窗和设置页。
- 弹窗收敛为“扫描 → 核对 → 填写”主流程，高级工具默认收起；固定填写操作，长字段列表不遮挡核对控件。
- 设置页以个人资料为先，桌面连接与 AI 配置分区；下方操作后的状态反馈保持视口可见。
- 桌面端分离服务、更新和隐私详情，待配对请求保持可见。
- 统一共享设计变量、插画、按钮、表单、键盘焦点和窄窗口布局，不引入远程字体或新的运行时依赖。
- 保留扫描、填写、配对、资料保存、模型和更新行为及现有控件契约。

## 验证

- Impeccable 检测零发现。
- 15 组单元/协议测试、26 组浏览器回归及完整桌面回归通过。
- 真实扩展扫描、填写、Agent、自动配对和资料同步通过。
- 实际 Electron 资料、PDF 和授权 UI 通过；360–1280px 渲染、键盘顺序、30 字段操作区和动态状态反馈通过。
- 独立代码审查的两项 Important 发现已修复；隐私与格式检查通过。
- `desktop/updater-ui-test.cjs` 的 Electron mock 在界面操作前出现 `require is not defined`；更新单元测试和渲染器测试通过，本版未修改更新逻辑。

## 发布门禁记录

- 同版本 Live AI 已通过：OpenRouter 凭证检查 200，3 个合成字段、5 条候选路径、4 项实际填写回读与 1 次模型恢复均成功，`valuesSent:false`，报告保存在 `dist/ai-live-verification.json`，`ok:true`。
- Live 验证还处理 provider 429 瞬时重试与慢响应；默认产品网关超时不变，仅显式验证配置允许更长上限。

- Windows 安装包、独立扩展 ZIP、`latest.yml`、blockmap 和 SHA256SUMS 已生成并核对；1121 项产物隐私扫描零发现。
- 打包后的 0.27.2 桌面程序已在测试图形参数下启动，四个主要区域渲染及本地服务启动通过。
- 不创建版本标签或 GitHub Release；保留 main 上的合并与版本提交。
