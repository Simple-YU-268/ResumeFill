# 0.29.0 · 平台工作流适配（开发测试版）

日期：2026-11-12。未发布正式 Release。

新增共享可见页面工作流：Moka、北森与智联校招采用严格 HTTPS 主机边界识别；登录、验证码、职位关闭、投递限制和志愿确认状态交给用户处理。不会点击投递入口、切换志愿或提交申请。未找到投递按钮不能作为职位关闭的证据。

北森新增 `.ux-standard-form` 卡片、`.form-item` 标签、必填标记及 Phoenix 单选下拉适配。教育记录按独立卡片排列，工作和实习沿用现有独立记录分配；未知区块和无法确定关系的家庭成员不自动匹配。Phoenix 只验收真实选中项，不把搜索输入当作成功。多选、复杂地区联动及只读日期仍需专门适配或手动填写。

Moka 保留已有组件、项目、家庭关系与年月精度适配，增加页面状态与简历解析流程。Moka 和北森确认上传应用内导入的原始 PDF 后，立即使旧计划失效；等待网页解析结束，重新扫描、核对再填。文件已选中不代表服务器接收或解析完成；不生成 PDF。

智联研究对象为校招工作流，依赖私有 schema/API 回写。本版独立使用可见表单与通用组件引擎，在 `/postprocess` 与 `/scrd/postprocess2` 志愿阶段停填。尚未覆盖智联全部产品、租户或私有接口。

扩展弹窗与 Electron 网站工作区使用同一个适配模块，显示平台状态；不在网页主世界暴露应用桥接。研究记录见 `docs/PLATFORM-WORKFLOW-RESEARCH.md`。竞品模块只作静态研究输入，不随产品分发或执行，未调用其业务后端。

本版验收使用合成页面与隔离浏览器资料；真实招聘站仍待逐站验收，不能据此承诺全站兼容。完整架构剩余工作见 `docs/ENGINE-IMPLEMENTATION.md`。

验收：`npm run test:all` 退出 0，覆盖标准 16 组、浏览器 29 组、桌面集成和原生 Electron 六项。`npm run build` 退出 0；包内程序再次通过北森专项与完整网站工作区测试（含 900px 布局）。宿主、preload、UI 和六份平台运行时文件与源码逐字节一致。`npm run release:check` 通过，源码隐私检查 225 项、产物隐私检查 1136 项无发现。安装包仅构建，未覆盖安装、发布或推送。
