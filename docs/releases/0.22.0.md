# ResumeFill Agent 0.22.0

少填一点，多一点可能。这次带来统一的插画界面，以及从已填写网页中学习个人资料的完整流程；同时汇总自上一发行版 0.18.0 以来的连接与表单兼容改进。

## 新变化

- **统一插画界面**：桌面端、插件和设置页共用文档小搭档、圆润按钮与清晰的三步入口，适配窄窗口和键盘操作。
- **学习手动填写**：重新扫描已填表单，预览新增 / 修改项，勾选后写入本地 JSON；敏感项单独确认，保存前检查网页及资料是否变化。
- **更稳的字段与控件匹配**：可见同源 iframe、Layui 下拉、最高学历 / 学位、多段经历隔离，以及已适配的特殊多级选择器与回读。
- **简化桌面连接**：本机自动发现、首次确认配对、后续重连和授权撤销。
- **一键更新**：从本仓库 Release 检查和下载更新，保留本地资料；未保存编辑及进行中的任务会阻止安装。
- **完整产品文档**：[产品 Wiki](https://github.com/Simple-YU-268/ResumeFill/wiki) 与仓库文档同步维护。

## 升级提醒

1. 先保存资料、模型设置与网页内容，完成或停止 Agent / PDF 任务。
2. 安装新版，或在旧版支持时使用“一键更新并重启”。
3. 在 Chrome / Edge 扩展管理页**重新加载 ResumeFill**。
4. 若网页仍运行旧脚本，保存内容后刷新表单并重新扫描。不要因普通连接问题直接重建凭据。

两端各自保存资料，不是实时双向合并。学习只处理可见表单和可见同源 iframe，不会自动提交申请；复杂网站及歧义项仍需人工处理。

- 8 组基础测试通过；本版相关的已安装扩展学习、同步、AI / 多级选择器与受限页面回归通过。
- 桌面页面以合成资料完成渲染检查，模拟桥接的更新界面回归通过。当前环境原生 Electron 启动测试无法运行，未将跳过计作通过。

- 不承诺所有招聘站点、真实模型或安装环境均兼容；回读一致不代表网站服务器已保存。
