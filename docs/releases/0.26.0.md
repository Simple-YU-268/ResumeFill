# 0.26.0 · 文档与记录归属升级（开发测试版）

日期：2026-10-26。本包不宣称任意招聘站通用自动填报，不自动提交申请。

## 功能

- work 数组新增可选 employmentType：employment / internship / unknown，可视化下拉编辑。旧资料不根据职位推断类型，不重排、不丢弃未知字段。
- 工作与实习按类型映射原数组索引；未分类资料在预览分配。跨模块重复分配阻止填写，记录分配绑定文档、模块结构及规范化资料摘要，变化后重新核对。
- 多个表单文档时先选择目标；诊断区区分隐藏、跨域、不透明来源、未就绪、旧运行时和没有字段。
- 支持同源父链可验证且具有文档身份的 srcdoc；不把任意 about:blank 视作可信。
- 支持开放 Shadow DOM 扫描、根内标签/菜单/radio、内联建议和手动学习读取。嵌套根、重复 ID、隐藏 Host 与重绘后失效均有回归。
- 根内未结构化补充答案绑定当前文档/根，重建后需核对，避免跨根复用同名答案；明确的 JSON 资料路径仍可复用。
- 不执行跨域 iframe 填写、不增加跨域授权；不读取封闭 Shadow DOM。

## 兼容性与限制

- 网页已经打开时，仅重载扩展不会升级页面脚本；先保存网页已填内容，再手动刷新并扫描。
- 资料缺类型时可能比旧版少匹配，这是防止工作和实习错用同一记录。请分类或明确分配，不会自动借用其他经历。
- Moka 未适配的只读日历、地区、远端搜索等限制仍存在；本版没有增加自主浏览器策略或任意脚本执行。
- 回读一致不等于服务端保存；保留人工保存和提交核对。
