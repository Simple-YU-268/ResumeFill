# ResumeFill Agent 0.24.2 — Moka 适配测试版

针对当前 Moka 页面的 sd-Select 自定义选择器补齐识别、容器内选项归属、真实候选点击与已提交显示值读回。此前将其中的搜索输入当成普通文本框，写入文字不能代表选择成功。

同时增强模块字段标题与教育/实习记录隔离，支持分段起止年月；区分证件类型与号码、电话区号与手机号。家庭信息要求先选择称谓，关系变化后重新扫描；不会用本人的身份资料代填家属。

合成回归验证普通下拉、两段教育记录的年月、真实选择与临时搜索文字隔离、证件类型及家庭关系保护。实际申请页面只进行了结构与候选检查，未自动填写、上传或提交。

**仍需手动处理**：该页面的出生日期日历弹窗、多级籍贯、附件上传，以及需要本人确认的资格、调剂等自定义问题。本版不把只读框中的显示文字当作已完成真实选择，也不推断承诺或自动提交申请。

安装后重载 ResumeFill 扩展，先保存网页已填内容，再刷新并重新扫描。新版脚本不会自动替换已打开页面的旧脚本。当前仍为测试版，尚未发布正式 Release。
