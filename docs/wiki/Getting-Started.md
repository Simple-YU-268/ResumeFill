# 安装与首次连接

## 下载

从 [官方发行页](https://github.com/Simple-YU-268/ResumeFill/releases/latest) 下载 `ResumeFill-Agent-版本-Setup.exe`。Windows x64 安装版包含桌面端、扩展和离线 OCR，不需要 Node.js。安装程序未代码签名，请核对下载来源和发行页的 `SHA256SUMS.txt`；无需关闭系统安全保护。

## 加载浏览器扩展

1. 启动桌面端，在“浏览器扩展”点击“打开插件目录”或“复制插件路径”。
2. 手动打开 `edge://extensions/` 或 `chrome://extensions/`，启用开发者模式。
3. 选择“加载解压缩的扩展”，载入桌面端提供的目录。
4. 在工具栏固定 ResumeFill，方便从招聘页面打开。

仅使用扩展时，可下载 `ResumeFill-Extension-版本.zip`，解压后加载。扩展基础规则匹配不强制依赖桌面端；本地 OCR 与桌面管理需要桌面服务。扩展尚未上架商店。

## 自动发现与配对

确认服务启动后，在插件点击“自动发现并连接桌面端”。浏览器若提示访问本机网络，按界面提示允许；回到桌面端核对浏览器并点击“允许此浏览器连接”。后续打开插件会自动发现、重连，可在桌面端撤销授权。

首次连接可载入桌面资料，扩展已有资料和未保存内容会保留。0.23.0 起，重连会检查两端差异；点击“检查桌面资料更新”，核对后同步所选项目。设置页“从桌面端读取资料”也进入差异预览，不再要求整份替换。两端不是实时双向合并，桌面正在运行时可手动再次检查，或重新打开插件触发检查。

发现只访问本机 `127.0.0.1` 的 17322–17324 三个端口及已保存地址，不扫描局域网。自动发现失败可使用设置页的配对码 / 文件入口；一次性码有效期 10 分钟，使用成功或重新获取后失效。

## 第一次填写

保存个人资料，打开招聘网站实际表单页，从工具栏打开插件扫描，核对路径和经历序号，再填写。最终申请由你提交。

## 更新

运行总览提供“一键更新并重启”：从本仓库 Release 下载并校验安装包。先保存资料与模型设置，完成或停止 PDF / Agent 任务。也可下载新 EXE 覆盖安装。

安装后需在浏览器管理页**重新加载扩展**。若页面仍运行旧脚本，先保存网页内容，再刷新表单重扫。更新保留本机资料目录，重要更新前建议导出备份。
