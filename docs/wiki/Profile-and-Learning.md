# 资料与表单学习

## 可视化资料与导入

桌面端支持基本信息、多段教育 / 工作 / 项目、技能简介、自定义资料和网站答案；可导入导出 JSON，尽量保留已有扩展字段。地区三级联动，切换上级会清空下级；日期保留实际精度。

保存后再在扩展中读取、核对；两端各有资料，不是实时同步。“导入 PDF 简历”优先提取文字，扫描页使用本地 OCR，也可强制全页 OCR。AI 语义解析需启用模型并授权发送原文，逐项核对后合并保存。限制为 15 MB、15 页、60000 字符。

## 学习手动填写

1. 在网页手动填写信息，不必先提交申请。
2. 点击“重新扫描并学习已填内容”。
3. 核对原值、网页值、记录归属与目标路径。
4. 勾选保存项目，敏感资料还需单独确认。
5. 点击“确认保存所选学习项”，再到管理页查看或导出 JSON。

精确同义字段归入对应路径；未知字段创建 `fieldAnswers`，保留标签、网站、页面、区块和经历序号，下次相同上下文可复用。不同网站的陌生字段不会无条件共用答案。明确、连续的新经历可建立记录；归属不明、目标冲突或记录序号有缺口时先整理。

修改项与敏感项默认不勾选。空白、占位、已识别的脱敏内容、密码、验证码和安全答案不学习；不会根据空白清空原资料。

只读取当前可见表单与可见同源 iframe，不覆盖其他分页、附件或未展开项。保存前再次读取所选网页值并检查本地资料，变化后需重新扫描。学习不向 AI 发送读取的值，不改写或提交网页。

## 备份

0.23.0 增加桌面到插件的逐项差异同步：空缺普通字段默认勾选，已有值、敏感字段和整组经历需选择，敏感项与整组经历还需确认。经历数组不会按下标推断同一条记录；选择整组时会替换该组，请核对。桌面空值不清空插件内容，网站答案与插件独有字段保留。保存前核对两端是否变化，并阻止当前页面未保存编辑或正在进行的填写。同步前的插件资料单独保存在 `resumeSyncBackup`；当前没有可视化恢复入口，建议定期导出 JSON。同步后需重新扫描网页。

每次学习前，扩展本地存储 `resumeLearningBackup` 保留一份上次资料与时间；后续学习会替换它。当前没有独立可视化恢复入口，重要资料仍建议定期导出 JSON。

误选记录时放弃预览，先选正确区块或在管理页整理经历，再学习；不要为绕过提示随意选另一条记录。
