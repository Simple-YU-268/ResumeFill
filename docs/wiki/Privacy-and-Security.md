# 隐私与安全

0.25.0 增加本机累计统计：记录扫描、主填写按钮处理次数、回读结果和 AI 建议次数。它们是操作次数，不是唯一岗位数或申请成功率；单项重试与 Agent 写入暂不并入主填写计数。扩展与桌面通过已授权的本机连接同步计数，不记录标签、简历值或网页地址，不发送外部遥测。

## 存储与配对

桌面资料在本机用户数据目录，可点击“打开数据目录”；扩展资料位于浏览器扩展本地存储。JSON 导出包含个人资料，请妥善保管。

桌面用 Electron safeStorage / Windows DPAPI 加密网关令牌与模型密钥。加密文件不能保证在另一台电脑或不同系统环境使用；不要直接搬运凭据。正常启动解密失败时先保留原文件，再按恢复流程处理。重建凭据会撤销连接、暂停 AI，不是普通连接失败的首选操作。

首次配对由桌面端确认，可撤销。发现只访问回环地址，不扫描局域网，不返回个人资料或长期令牌。会话令牌与云端密钥分开管理。一次性配对码 10 分钟有效，勿公开分享。

## 数据流

| 操作 | 数据去向 |
| --- | --- |
| 本地扫描、规则匹配、编辑、学习 | 本机 / 当前网页上下文；学习不请求外部模型 |
| 网页填写 | 值进入招聘网站表单；网站可能自行监听、保存输入，即使尚未提交 |
| 主动 AI 匹配 | 配置的模型服务；默认仅未解决标签、必要上下文与路径 |
| 手动勾选附带资料值 | 配置的模型服务；包含请求预览中的候选值 |
| PDF AI 解析 | 授权后，提取的简历原文发给配置的模型服务 |
| PDF / 网页 OCR | 本机；网页截图发给本机桌面端 |
| 检查 / 下载更新 | GitHub API 与本仓库发行资产，不附带简历 |

标签和上下文本身也可能含私人内容，发起模型请求前请确认范围。

密码、验证码、安全答案不参与自动匹配或学习。敏感学习项需确认。申请由用户提交，回读不能替代内容准确性与后端保存检查。

Issue、截图、日志和公开仓库不得包含密钥、身份证号、完整简历、浏览器配置或会话链接。源码与发行包会扫描，但模式扫描不能证明绝无敏感内容，见 [公开审查记录](https://github.com/Simple-YU-268/ResumeFill/blob/main/PRIVACY-REVIEW.md)。
