# 常见问题

## 扩展商店无法扫描

出现 `The extensions gallery cannot be scripted` 时，切回实际招聘表单，从工具栏打开插件。内部页面和扩展商店禁止注入脚本，不要关闭安全保护。

## 找不到桌面端

确认服务启动、两端版本一致、本机访问权限已允许，并检查桌面是否有待批准的配对。自动发现失败可使用手动配对。不要直接重建凭据或公开令牌。

## 更新后还是旧界面

安装 EXE 后，在扩展管理页重新加载插件。旧表单脚本可能仍运行，先保存网页内容，再刷新表单重扫。

## 项目 / 实习记录串用

核对 JSON 记录数量和顺序。用“只处理选定区块”选择单条经历容器与序号，归属不明时不要选第一条。多个字段指向同一路径但值不同，学习会要求先核对。

## 下拉没选成功

控件可能异步加载、虚拟滚动或多级浮层。插件需要唯一候选和真实选中状态；名称重合、分数边界重叠、列表不完整时转人工。只输入文本不等于选中条目。

## 日期不足 / 学习预览失效

资料只有年月而网页要求年月日时补充真实日期，不假设每月 1 日。网页内容或 JSON 在预览后改变时，重新扫描并学习，以免覆盖新内容。

## 模型错误

| 状态 | 排查 |
| --- | --- |
| 401 | 鉴权被拒绝；检查密钥有效性、保存情况和浏览器会话。不要公开密钥。 |
| 404 | 检查完整接口路径与模型 ID，模型可能不存在或不可用。 |
| 403 | 查看服务商权限、地区、条款限制；不能仅凭状态码推断具体原因。 |
| 429 | 检查余额、额度、速率和并发限制，稍后重试。 |

先在桌面端保存并测试，区分网络、鉴权、协议与实际匹配问题。测试成功不保证所有字段都有建议。

## 下拉回空与页面脚本版本

0.24.1 会在注入模块前核对已运行的页面脚本。看到“页面仍在使用旧版或未就绪的填表脚本”时，先保存网页已填内容，手动刷新表单再扫描；不会自动刷新、清空页面或重建配对凭据。

如果仍回空，记录控件名称与发生时机。检查点中的 `extension_version`、`page_runtime_version` 和 `diagnostic` 可用于区分版本不一致、真实选项清空、只显示为空等情况。诊断标志不包含具体填写值；检查点本身仍可能含字段标签、选项和页面信息，分享前应审阅脱敏。

## Moka 自定义下拉

0.24.2 测试版增加了 `sd-Select` 组件适配：区分输入搜索文字与真实选中值，按当前控件容器点击候选，再读取已提交的显示值；重复经历按各自记录匹配，起止年月分别处理。

安装测试版后重载扩展，先保存网页已填内容，再刷新并重新扫描。该版仍不自动处理此类页面的生日日历弹窗、多级籍贯或附件；资格、调剂与承诺等问题应由本人确认。看到这些项未完成时不要以重复运行代替人工核对。实际申请最终由用户提交。


### AI 没有参与字段匹配

0.24.3 起，主动匹配会检查尚未解决、资料为空和较弱的自动匹配；人工选择、已回读成功及已保存的映射不会自动覆盖。标准路径不存在时，可从同模块非空资料生成候选。未知基本资料字段最多提供 48 条路径，明确经历最多 12 条；没有明确经历归属时不跨记录猜测。

先看插件的 AI 状态：未启用模型、请求失败、本地网关规则和模型返回建议是不同状态。显示“本地网关规则”表示本次没有使用上游模型。默认只发送字段标签和候选路径，不发送简历值。返回建议仍需核对后填写；资料缺失、关系不明、附件与承诺不会因启用 AI 自动完成。
