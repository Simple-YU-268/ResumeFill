# 常见问题

## 扩展商店无法扫描

出现 `The extensions gallery cannot be scripted` 时，切回实际招聘表单，从工具栏打开插件。内部页面和扩展商店禁止注入脚本，不要关闭安全保护。

## 找不到桌面端

确认服务启动、两端版本一致、本机访问权限已允许，并检查桌面是否有待批准的配对。自动发现失败可使用手动配对。不要直接重建凭据或公开令牌。

## 更新后还是旧界面

安装 EXE 后，在扩展管理页重新加载插件。旧表单脚本可能仍运行，先保存网页内容，再刷新表单重扫。

## 项目 / 实习记录串用

核对 JSON 记录数量和顺序。用“只处理选定区块”选择单条经历容器与序号，归属不明时不要选第一条。多个字段指向同一路径但值不同，学习会要求先核对。

## 下拉没选成功

控件可能异步加载、虚拟滚动或多级浮层。插件需要唯一候选和真实选中状态；名称重合、分数边界重叠、列表不完整时转人工。只输入文本不等于选中条目。

## 日期不足 / 学习预览失效

资料只有年月而网页要求年月日时补充真实日期，不假设每月 1 日。网页内容或 JSON 在预览后改变时，重新扫描并学习，以免覆盖新内容。

## 模型错误

| 状态 | 排查 |
| --- | --- |
| 401 | 鉴权被拒绝；检查密钥有效性、保存情况和浏览器会话。不要公开密钥。 |
| 404 | 检查完整接口路径与模型 ID，模型可能不存在或不可用。 |
| 403 | 查看服务商权限、地区、条款限制；不能仅凭状态码推断具体原因。 |
| 429 | 检查余额、额度、速率和并发限制，稍后重试。 |

先在桌面端保存并测试，区分网络、鉴权、协议与实际匹配问题。测试成功不保证所有字段都有建议。
