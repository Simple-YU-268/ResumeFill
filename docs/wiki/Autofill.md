# 填写与匹配

## 扫描、核对、填写

扫描结合可见标签、位置、表格 / 定义列表关系、经历卡片与站点规则，不仅依赖网页内部代码名。预览中检查字段、JSON 路径、经历序号及值；已有值默认保留，主动选择允许覆盖后才尝试覆盖。

填写后独立回读，不能确认真实选项或值不一致时报告问题。**回读一致不等于网站服务器已保存**，最终保存和申请提交需自行核对。

## 多段经历

教育、工作 / 实习和项目必须对应具体记录。最高学历仅在层次明确且唯一时自动选择；并列或资料不足时不任取一条。

归属不清时，展开“只处理选定区块”，列出并定位容器，选择类目及起始经历序号，再“仅扫描此区块”。明确的多张卡片依次对应不同记录；否则选择单条经历容器。范围失效时停止，不自动扩大。

区块模式不自动新增或保存网页经历卡片；点击“恢复整页扫描”解除范围。

## 下拉、地区与日期

- 固定选项共用同义词词典，含义不同的政治状态等不混用。
- 地区优先完整省、市、区县；详细街道仍为文本。词典采用 2023-06-30 数据，未收录或歧义项需核对。
- 日期保留年 / 月 / 日精度，不虚构缺失的月份或日期。资料只有年月而网页要求完整日期时需补充。
- 已适配的复杂选择器核验真实菜单项。51job 类型多级引用控件会检查唯一末级、完整路径和回显；重名、超限、列表不完整转人工。
- 英语等级可结合同条语言记录的分数。数值区间边界重叠时不取第一个；月薪与年薪不自动混算。

## iframe 与动态页面

支持可见同源 iframe 和经同源父链验证的 srcdoc。发现多个表单时先在“选择表单文档”中指定目标，只处理选中的文档。隐藏、跨域、不透明 sandbox、旧运行时或没有字段时显示扫描诊断；跨域文档不执行填写。刷新、跳转或隐藏原表单后需重扫。iframe 暂不使用整页截图 OCR，避免坐标混淆。

开放 Shadow DOM 可扫描、匹配与填写，标签、菜单和 radio 保持根内归属；支持内联建议和学习读取。不具备结构化归属的 Shadow 根内补充答案限定当前文档和根，文档重建后需重新核对；已有明确 JSON 路径的个人资料仍可复用。封闭 Shadow DOM 不进入扫描，不保证所有富文本或自定义组件都可执行。

工作/实习保留在同一个 work 数组，通过可选 employmentType 区分 employment（工作）、internship（实习）、unknown（未分类）。旧资料不自动推断类型；在桌面或扩展资料编辑器选择类型，或在扫描预览中分配独立记录。重复分配会阻止填写；资料或模块结构变化后需重新核对。

动态新增字段后可重新扫描。Agent 可暂停、停止与继续；中断后先查看失败原因，再核对页面和服务连接。
