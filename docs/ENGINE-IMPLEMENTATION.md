# M1-M9 实现跟踪

此表按运行代码记录进度，不以架构蓝图代替验收。PDF 产出不在目标范围，最终投递由用户在网页完成。

| 模块 | 当前实现 | 仍需实现或验收 |
| --- | --- | --- |
| M1 detect | 标签来源、ARIA 优先级、valueType/组件信号、字段 identity/指纹/风险、iView 根与选项回读 | 选择器输出与完整 valueType 覆盖、更多真实组件验收 |
| M2 match | 四态接口及扩展预览、加权候选、记录/家庭隔离、资料级 autoFill 策略；禁止项退出填表和 AI 候选 | 完整 valueType 语义、分数解释、更多灰区交互验收 |
| M3 fill | 原生 setter、InputEvent、composed change/富文本、现有选择器独立回读 | focus/blur 所有权、checked setter、真实框架覆盖验收 |
| M4 adapt | 唯一同身份替换控件重定位；语义重扫与普通输入条件回滚；表单内 MutationObserver 与资源活动稳定计数，150ms 静止/1200ms 超时、50 项发现上限、必清理观察器 | 新字段目前提示核对；三轮续填与语义双通道、复杂控件回滚仍需实现 |
| M5 upload | 桌面原始 PDF 导入/删除、元数据常驻显示、授权网关、双步附件确认；唯一可见归属的隐藏 file；桌面→扩展→网页原字节端到端验收通过 | 多附件类型匹配（当前仅投递用 PDF 简历）、上传后服务器接收状态仍由网页核对 |
| M6 submit | 可见必填/格式/挑战提示、语义漂移与回读变化/未确认项、提交候选检查；无自动点击 | 预览待核对事项联动、高亮定位；origin/文档边界由 page-bridge 执行，预算由队列执行 |
| M7 courier | 队列状态机、预算与公司配额、任务列表、用户确认回执；重试/跳过/中断恢复；脱敏导出及桌面持久化同步验收 | 职位筛选、简历变体路由、历史归档与配额保留 |
| M8 desktop | 资料编辑器、共享策略页、经历删除/撤销时策略重排；任务看板筛选；原始 PDF 与元数据、模型/OCR | 审计回放、简历变体管理 |
| M9 extension | 四态预览、附件确认、提交前检查、任务入口 | 协议收敛、content 职责拆分、窄屏/键盘/对比度全面验收 |

发布前还需统一版本、发布说明和隐私审查，并完成标准、浏览器、桌面及安装包验证。当前提交为持续开发检查点，不代表全部模块完成。

2026-11-11 验证：标准测试 16 组、浏览器回归 26 组、桌面集成测试及新增附件/策略/看板测试通过。策略接入后额外运行扩展完整工作流与桌面集成测试。Electron 原生窗口测试因进程无法启动而跳过，不能将此项记为通过。
