# M1-M9 实现跟踪

此表按运行代码记录进度，不以架构蓝图代替验收。PDF 产出不在目标范围，最终投递由用户在网页完成。

| 模块 | 当前实现 | 仍需实现或验收 |
| --- | --- | --- |
| M1 detect | 标签来源、valueType/组件信号、iView 根与选项回读 | 完整信号模型、ARIA 优先级重整、逐字段身份指纹、全类型覆盖 |
| M2 match | 四态接口及扩展预览、加权候选、记录/家庭隔离 | 完整 valueType 语义与策略列、分数解释、灰区交互验收 |
| M3 fill | 原生 setter、InputEvent、composed change/富文本、现有选择器独立回读 | focus/blur 所有权、checked setter、真实框架覆盖验收 |
| M4 adapt | 唯一同身份替换控件重定位；填写后语义重扫；普通输入条件回滚 | 有界 MutationObserver 增量发现、语义双通道、空闲判定、复杂控件回滚 |
| M5 upload | 桌面原始 PDF 导入/删除、授权网关、双步附件确认、字节回读测试 | 应用到扩展完整端到端、隐藏原生 file 的可见组件归属、多附件类型匹配 |
| M6 submit | 可见必填/格式问题与提交候选检查；无自动点击 | 回读失败/人工事项汇总、受保护挑战、origin/path/任务预算联动、高亮定位 |
| M7 courier | 队列状态机、预算与公司配额、扩展任务列表、用户确认回执 | 职位筛选、简历变体路由、取消/恢复/清空、导出与持久化验收 |
| M8 desktop | 既有资料编辑器、模型/OCR、原始 PDF 附件入口 | autoFill 列、投递看板、审计回放、附件元数据常驻展示 |
| M9 extension | 四态预览、附件确认、提交前检查、任务入口 | 协议收敛、content 职责拆分、窄屏/键盘/对比度全面验收 |

发布前还需统一版本、发布说明和隐私审查，并完成标准、浏览器、桌面及安装包验证。当前提交为持续开发检查点，不代表全部模块完成。
