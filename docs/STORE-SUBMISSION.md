# 商店提审准备

当前扩展仍使用开发者模式，尚未取得 Chrome / Edge 商店审核与上架身份；桌面安装包也未取得代码签名证书。本文件是准备材料，不表示已经提交或获批。

产品用途：用户主动扫描招聘网页，将本机已有简历资料匹配到可见字段，核对后填写并独立回读；不自动提交申请、不处理验证码或密码。

权限说明：

- `activeTab`：仅在用户调用扩展时访问当前招聘页面、核对表单及按需截图。
- `scripting`：注入可见字段识别、控件操作与回读脚本。
- `storage`：本机资料、映射、选项偏好与仅含累计次数的统计。
- 可选 HTTPS host：用户填写并授权的模型接口；默认不请求任何云模型。
- 可选 localhost / 127.0.0.1 host：已配对的桌面端网关和本地 OCR。

数据披露：字段 AI 默认发送标签与候选路径；附带资料值须显式选择，选项模型拒绝身份号码等敏感值。PDF 全文语义解析另有独立确认。网页截图只发本机 OCR，不留存；没有外部统计遥测。家庭信息与同步遵守敏感资料核对规则。

提审前需要：填写真实发布者与支持联系方式、提供有效隐私政策公开地址、按商店当前要求复核权限与远程 AI 声明、使用合成资料录制演示、确认版本与隐私门禁通过。不要上传用户简历、检查记录、API 密钥或真实网页截图作为审核样本。

未自动提交提审：账号、发布者身份、证书及可能的法律协议由维护者完成。收到正式商店扩展 ID 后再配置对应更新和配对说明，不伪造商店安装链接。
