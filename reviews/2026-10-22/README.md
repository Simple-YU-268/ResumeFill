## 跨专家共识的关键结论

### 最高优先级（多专家交叉确认）

1. **隐私闸门缺口**：check-public-package.cjs 跳过两字中文姓名（length>=3 阈值）；option-match.js 的选项匹配会把简历值发给模型，且不拦截身份证号类敏感值；PRIVACY-REVIEW 停留在 v0.23.0，滞后于发版。
2. **打包完整性**：desktop/prepare.cjs 手工 33 文件白名单无完整性断言，且不清理目标目录（被移除的文件会残留进安装包）——CTO 明确划线：修复前不建议下一次正式发布。
3. **版本一致性**：local-server/server.cjs 硬编码 VERSION='0.16.0'；桌面端 0.24.2 vs 根包 0.24.1 漂移；22s vs 25s 超时口径不一致。
4. **稳定性**：content.js 批量回读缺逐条 try/catch（一个字段抛异常丢失全部结果）；controller.cjs 配置 JSON.parse 无保护（启动崩溃）；配对码长度按字符而非字节校验（timingSafeEqual RangeError）。

### 战略层结论（CPO）

- 核心填写闭环在 0.23–0.24 已真正成立；瓶颈已从"功能不够"转移到"装不上、发不出、没回看"。
- 下一版本最值钱的动作：复测并发行 0.24.1 → 补隐私审查 → 冲商店上架。功能面唯一值得做的是本地统计仪表板。
- 不做清单：云同步/账号体系、自动提交/代填验证码、通用任意网站承诺。

### 状态

评审建议尚未实施，等待确认执行范围（速修清单 / 速修+短期 / 全面执行）。
